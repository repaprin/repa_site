# REPA Website

Sito vetrina statico per il progetto **REPA – aRtificial intElligence for Process Analytics**.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository GitHub, ad esempio `repa-site`.
2. Carica i file `index.html`, `style.css` e la cartella `assets`.
3. Vai su **Settings → Pages**.
4. In **Build and deployment**, scegli:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Salva.
6. Il sito sarà online all'indirizzo:

```text
https://TUO-USERNAME.github.io/repa-site/
```
